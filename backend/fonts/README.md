# Bundled fonts

| Font | File | Licence | Dùng cho |
|---|---|---|---|
| Patrick Hand (Patrick Wagesreiter) | `patrickhand/PatrickHand-Regular.ttf` | SIL OFL 1.1 (`patrickhand/OFL.txt`) | Chữ thoại kiểu viết tay cho đích vi/en (có đủ dấu tiếng Việt). |

Font CJK (Noto Sans CJK) và DejaVu Sans được cài từ gói Debian trong `Dockerfile`.
Dockerfile copy thư mục này vào `/usr/share/fonts/truetype/` của image.
